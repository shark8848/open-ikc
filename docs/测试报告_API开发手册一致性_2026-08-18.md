## 3. 发现项与建议

- **[P2] 新建知识库 updateTime 为 null**：创建响应含 createTime/updateTime 字段，但 updateTime 在创建时为 null（未更新语义）。建议手册补充说明，避免调用方误判字段缺失。
- **[P2] 空字符串 kbName 未做非空校验**：服务端接受 kbName="" 并创建空名知识库（返回 000000）。建议补充非空校验（100001），或在手册中明确该限制。
- **[P2] sync 解析命中既有 queued 任务时复用状态，不强制完成**：幂等设计：同一文档已有 queued/running 任务时，sync 请求复用当前状态（queued）而非请求内完成。与手册 §6.3.1「executeMode=sync 请求内返回内联结果」存在语义差异，建议确认产品预期并补充文档说明。
